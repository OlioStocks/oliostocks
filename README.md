# Vanstone Financial — GitHub Pages Website

A minimal, premium one-page website using a dark / gold OlioBot-inspired visual system.

## Before publishing

1. Open `script.js`.
2. Replace:
   `PASTE_GOOGLE_CALENDAR_BOOKING_LINK_HERE`
   with the Google Calendar Appointment Schedule booking URL.
3. Add the final OlioBot demo video at:
   `assets/oliobot-demo.mp4`
4. If desired, replace the CSS/text brand mark with the official Vanstone Financial logo.
5. Commit the files to the GitHub repository used for GitHub Pages.
